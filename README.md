# 网页交互术语图鉴

> 说得出名字，才写得清需求。

**在线访问：<https://guo25476688-cmd.github.io/web-interaction-glossary/>**

一本给（新手）产品经理用的**交互辞典**：每个术语都看得见、点得动。你见过那个效果，却不知道它叫什么，于是 PRD 写不清、和设计开发说不清、也没法让 AI 准确做出来——这个网站就是用来解决这个问题的。

## 能帮你做什么

| 工作场景 | 对应功能 |
| --- | --- |
| 写 PRD / 需求文档 | 每个术语附「写进 PRD」要点清单（触发、状态、边界情况），可一键复制 |
| 和设计、开发沟通 | 「易混淆」对比（如 Modal / Drawer / Popover 何时用哪个），要点清单也可当评审检查表 |
| 用 AI 做原型 | 每个术语附「对 AI 说」提示词；「页面区块」分类（Hero、定价表、CTA 等）方便搭整页 |
| 竞品分析 | 把看到的交互加入「我的清单」，一键复制竞品拆解表；附灵感图库外链找真实案例 |

其他功能：

- **可交互实例**：170 个术语，每个都配一个可以亲手操作的小实例
- **搜索与分类**：按 8 个分类浏览（见下表），支持中英文搜索
- **「不知道叫什么」反查**：用大白话描述你看到的效果（如「鼠标放上去冒出来的小字」），找到对应术语
- **我的清单**：收集多个术语后，批量复制 PRD 要点、AI 原型提示词或竞品拆解表（保存在浏览器本地）
- **简繁切换**：内容以简体书写，繁体由 [opencc-js](https://github.com/nk2028/opencc-js) 实时转换，英文术语始终保留

## 使用

无需安装依赖、无需构建，用浏览器直接打开 `index.html` 即可。

## 文件结构

```
index.html            页面骨架与样式
js/helpers.js         简繁转换、实例共用的样式和小工具（D 对象）
js/terms-basic.js     分类、灵感图库，以及最初的 60 个术语
js/terms-more-1.js    扩充术语：反馈提示 / 导航 / 输入控件 / 内容展示
js/terms-more-2.js    扩充术语：移动端与手势 / 引导与系统状态 / 动效 / 页面区块
js/terms-more-3.js    扩充术语：反馈提示 / 按钮与输入 / 导航（第三批·上）
js/terms-more-4.js    扩充术语：内容展示与社交 / 移动端 / 系统状态（第三批·下）
js/app.js             搜索、渲染、我的清单
```

## 如何新增一个术语

在任意一个 `js/terms-more-*.js` 的 `TERMS.push(...)` 里，仿照已有条目添加一个对象：

```js
{
  id: 'tooltip',            // 唯一标识，英文小写
  cat: 'feedback',          // 分类 id，见 terms-basic.js 里的 CATS
  zh: '文字提示',            // 中文名（用简体书写）
  en: 'Tooltip',            // 英文术语
  alias: ['气泡提示'],       // 别名
  plain: '鼠标放上去时冒出来的一行小字说明', // 大白话，同时用于反查，越口语越好
  desc: '给图标或按钮补一句简短解释。',     // 什么时候用
  prompt: '给这个图标加一个 Tooltip……',   // 「对 AI 说」：可直接发给 AI 的提示词
  vs: '内容多或需要点击操作用 Popover。',  // 可选，易混淆对比
  spec: ['触发元素与提示文案', '……'],     // 「写进 PRD」：需求要点清单
  ref: ['saaspo'],                        // 可选，真实案例图库，取值见 REFS
  demo: `<button>……</button>`             // 实例区的 HTML
}
```

说明：

- 最初的 50 个术语，其 `vs` 和 `spec` 集中写在 `terms-basic.js` 的 `var PM = {...}` 里，按 `id` 对应；新术语直接写在对象里即可。
- 实例里的交互通过 `D` 工具对象完成，例如 `D.tog(this, '.ov')` 表示在当前实例内切换 `.ov` 元素的显示与隐藏。需要新的交互逻辑时，在术语文件顶部添加 `D.xxx = function ...`。
- 灵感图库只放外链，不要把别人网站的截图放进仓库。
